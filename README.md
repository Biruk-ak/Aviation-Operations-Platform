# Aviation Operations Platform

Enterprise aviation management web application.

## Stack

- **Frontend:** React (Vite)
- **Backend:** Node.js + Express
- **Mobile:** React Native clients for crew & ground ops

## Modules

Aircraft · Pilots · Flight Planning · Maintenance · Ground Operations ·
Airport Dashboard · Cargo · Weather · Navigation · Fuel Management ·
Crew Scheduling · Ticketing · Analytics · Mobile Apps
